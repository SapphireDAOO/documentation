# Core Contracts

List of  core contracts

| Contracts                                                       | Description                                                                                                                                                                                                                                                  |
| :---------------------------------------------------------------: | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
| [PaymentProcessorStorage.sol](paymentprocessorstorage.sol.md)   | It is an ownable smart contract that acts as the persistent state and configuration layer for the payment processing system. It manages global parameters such as the next invoice ID, fee settings, hold periods, gas thresholds, and authorized addresses. |
| [SimplePaymentProcessor.sol](simplepaymentprocessor.sol.md)     | Enables sellers to create invoices, buyers to pay through escrow and funds to be securely released or refunded based on transaction state.                                                                                                                   |
| [PaymentAutomation.sol](paymentautomation.sol.md)               | Keeper adapter that drives SimplePaymentProcessor's due-task queue, exposing both a Chainlink CRE (`onReport`) and a Gelato Web3 Functions (`checker`) entrypoint.                                                                                            |
| [IntermediatedPaymentProcessor.sol](intermediatedpaymentprocessor.sol.md) | Manages single and meta-invoices with escrow, dispute resolution, ERC20/native token support and intermediated-platform-controlled operations.                                                                                                     |
| [Escrow.sol](escrow.sol.md)                                     | This contract is an escrow used by a payment processor to securely hold funds for a specific invoice. It supports ETH or token withdrawals authorized only by the payment processor.                                                                         |
| [EscrowFactory.sol](escrowfactory.sol.md)                       | Abstract factory inherited by a payment processor to deploy Escrow contracts deterministically via CREATE2, so escrow addresses can be predicted before deployment.                                                                                          |
| [Notes.sol](notes.sol.md)                                       | This contract stores encrypted order notes and tracks per-user opened state for SapphireDao payment flows                                                                                                                                                    |
| [OracleManager.sol](oraclemanager.sol.md)                       | Manages Chainlink price feeds and L2 sequencer uptime checks used by the IntermediatedPaymentProcessor to convert USD invoice prices into the equivalent payment token amounts.                                                                               |
| [MultiSig.sol](multisig.sol.md)                                 | Multisignature governance contract that gates privileged admin calls into the payment processors and storage contract behind a propose/approve/execute flow across a defined signer set.                                                                    |
| [MasterDeployer.sol](masterdeployer.sol.md)                     | Deploys the full payment processor system (MultiSig, Notes, SimplePaymentProcessor, PaymentAutomation, OracleManager, IntermediatedPaymentProcessor, PaymentProcessorStorage) deterministically via CREATE2, so PaymentProcessorStorage's address is predictable and can authorize both processors at construction. |
